# 模型处理管线

上传入口只接受 GLB、STL 和包含 OBJ/MTL/纹理的 ZIP。所有输入必须声明源单位、LPS/RAS 坐标系以及分层名称；STL 不携带可靠单位，因此缺少单位时必须拒绝。

处理顺序为：隔离区上传 → SHA-256 校验 → ZIP 安全检查 → 几何边界和资源限额检查 → 固定镜像转换 → 质量报告 → GLB 多档优化 → 发布不可变对象。原文件保留，手机查看器只读取 low/medium/high GLB。

转换器通过参数数组启动 Docker，禁用网络并使用只读根文件系统，禁止拼接 shell 命令。生产前必须把 `CONVERTER_IMAGE` 中的占位摘要替换为已审计镜像的真实 SHA-256；未通过误差、边界或三角面检查的输出不可发布 Manifest。

对象键包含源文件摘要和规范化分层名，因此同一输入可重现且发布后不可覆盖。转换报告记录镜像摘要、参数、转换前后边界、三角面数和抽样顶点最大误差。
