# 三维长度与直径测量工具设计

## 目标

让当前测量工具栏中的“长度”和“直径”按钮真正可用：用户进入工具后，在已加载的三维模型表面点击两点，界面显示两个端点、连接线和毫米数值；测量结果可以撤销、清空，并随模型视角变化保持正确跟随。

## 范围

本次只补齐当前三维查看器中的长度和直径测量，不新增 CT 切片测量、后端持久化或新的工具栏布局。复用现有 `InteractiveTools`、`ToolRecords` 和 `ViewerEngine`，避免影响已有三维标注、分层移动和剖切功能。

直径沿用现有两点测距语义：用户点击病灶或目标区域的两个边缘点，显示两点间距离。圆形轮廓拟合不在本次范围内。

## 用户交互

1. 点击“长度”或“直径”后，查看器进入对应测量模式并暂停模型旋转/平移控制。
2. 点击可见模型表面：
   - 第一次点击保存一个局部坐标锚点，并立即显示端点；
   - 第二次点击保存第二个锚点，提交一条完整记录，显示第二个端点、测量线和数值标签；
   - 完成后可以继续点击，创建下一条同类型测量。
3. 点击背景、隐藏图层或被剖切区域时不创建点，并显示可理解的提示。
4. “新建”清除当前未完成的点，不删除已完成记录。
5. “撤销”先撤销当前未完成的最后一个点；没有未完成点时撤销最后一条当前记录。
6. “清空”清除长度或直径测量记录，同时清除当前未完成点；标注记录不受影响。
7. “关闭”退出测量模式，清除未完成点，并恢复模型旋转/平移控制；已完成记录保留在当前查看会话中。
8. 模型旋转、缩放、图层移动和视图刷新时，端点、连线和标签重新投影，数值不因相机变化而改变。

## 设计

### 交互层

`InteractiveTools` 继续负责画布指针事件、Three.js 射线拾取、可见性/剖切过滤和工具状态。长度、直径使用同一套“两点记录”流程，仅通过 `tool` 字段区分记录类型。

拾取后将命中点转换为所属图层的局部坐标保存。测量计算时通过已有 `resolve` 将锚点还原到模型测量坐标，因此旋转相机、缩放视图和移动图层不会改变已保存的物理距离。

### 记录层

`ToolRecords` 负责 pending 点、完整记录和历史快照。两点完成后计算距离并生成毫米标签；记录保持现有 `ToolRecord` 结构，保证方案序列化与已有标注记录兼容。

### 渲染层

`InteractiveTools.refresh()` 为当前 pending 点和完整长度/直径记录创建端点与线段 overlay，并为完整记录创建数值标签。overlay 使用不可深度测试的高渲染顺序，使测量结果在模型表面上清晰可见。每次刷新前释放旧的几何体、材质和 DOM 标签，避免重复显示或资源泄漏。

### 查看器接线

`ViewerEngine` 保持现有 `activateTool`、`toolCommand` 和 `viewer-tools` 事件接口。React 工具栏只负责发出工具/命令，测量状态由引擎事件更新；关闭测量时继续使用现有的 `activateTool(null)` 路径恢复控制器。

## 错误处理

- 非有限坐标拒绝写入记录，并显示现有中文错误信息。
- 没有射线命中时不改变 pending 或完整记录，只更新“请点击可见模型表面”提示。
- 点击不满足两点要求时只保留 pending 点，不提前创建完整记录。
- 空记录执行撤销或清空时不报错、不影响标注记录。
- 组件销毁或模型切换时释放测量 overlay 和标签。

## 测试策略

### 单元测试

- `ToolRecords`：长度/直径两点后生成记录；撤销 pending 点；撤销完整记录；清空只影响当前测量类型；非法坐标不落盘。
- `InteractiveTools`：点击模型表面产生 pending/完整记录；点击背景不产生记录；隐藏对象和剖切命中不产生记录；视角变化后记录仍引用同一锚点。

### 集成/端到端测试

- 查看器点击“测量”后出现当前工具栏，点击“长度”和“直径”能切换 active 状态。
- 真实模型页面中完成两次点击后可看到测量线、端点和毫米数值。
- 新建、撤销、清空、关闭分别验证；关闭后模型可以重新旋转。

## 验收标准

- 长度和直径按钮均可进入可操作模式。
- 在可见三维模型表面点击两点后，显示两端点、连线和数值。
- 点击背景不会新增测量。
- 隐藏图层和剖切掉的模型不会被拾取。
- 旋转/缩放不改变测量值，图形仍跟随模型。
- 撤销、清空、关闭行为符合上述交互定义，且不破坏已有标注功能。
- 前端相关单元测试、类型检查、lint、构建和可执行的端到端测试通过。
