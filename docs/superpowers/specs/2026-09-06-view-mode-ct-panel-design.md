# 视图模式与横断面显示设计

## 目标

调整查看器的视图显示行为，使默认三维查看更简洁，并让横断面影像只在用户明确选择“视图 → 三维+横断面”时出现。

## 行为

- 永久删除 `Image3D`、网址、关闭和更多按钮组成的顶部网站栏。
- 保留“模型/下载”标签栏和上下文工具栏。
- 默认视图仍为“三维”，此时只显示三维模型和底部图层栏，不渲染 CT/横断面预览。
- 选择“视图 → 三维+横断面”后，显示现有的三维模型与 CT 横断面上下分屏区域。
- 选择其他视图时不显示 CT 横断面预览；本次不改变其他视图的命名和菜单行为。

## 实现边界

`ViewerShell` 负责根据 `activeView` 决定是否渲染 `CtPreview`，并移除顶部网站栏 JSX。`ContextToolbar` 保持视图菜单和选中状态逻辑不变。相关 CSS 仅保留现有 CT 面板样式，必要时调整工作区在无 CT 面板时占满剩余空间。

## 验证

- 组件测试确认顶部网站栏不存在。
- 组件测试确认默认视图不渲染 CT 预览。
- 组件测试确认选择“三维+横断面”后渲染 CT 预览。
- 组件测试确认“模型/下载”和工具栏仍存在。
- 运行前端测试、类型检查、Lint 和生产构建。
