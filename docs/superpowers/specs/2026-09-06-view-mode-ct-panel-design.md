# 视图模式与横断面显示设计

## 目标

调整查看器的视图显示行为，使默认三维查看更简洁，并让横断面影像只在用户明确选择“视图 → 三维+横断面”时出现。

## 行为

- 永久删除 `Image3D`、网址、关闭和更多按钮组成的顶部网站栏。
- 保留“模型/下载”标签栏和上下文工具栏。
- 视图选项与显示内容严格对应参考图：
  - `三维`：只显示三维模型。
  - `影像`：只显示横断面影像。
  - `三维+横断面`：上方三维模型、下方横断面影像。
  - `冠状面`：只显示冠状面影像。
  - `矢状面`：只显示矢状面影像。
  - `三维+冠状面`：上方三维模型、下方冠状面影像。
  - `三维+矢状面`：上方三维模型、下方矢状面影像。
- 默认视图仍为“三维”。
- “模型/下载”和上下文工具栏在所有模型视图中保留；顶部网站栏在任何视图中都不显示。

## 实现边界

`ViewerShell` 负责根据 `activeView` 选择模型、影像或上下分屏布局，并移除顶部网站栏 JSX。`ContextToolbar` 保持视图菜单和选中状态逻辑不变。`CtPreview` 接收影像方向，展示横断、冠状或矢状面对应的状态。相关 CSS 使用单面板或上下分屏布局；只显示影像的模式不渲染三维画布，避免出现错误的组合内容。

## 验证

- 组件测试确认顶部网站栏不存在。
- 组件测试确认七个视图选项分别渲染正确的单面板或上下分屏内容。
- 组件测试确认“模型/下载”和工具栏仍存在。
- 运行前端测试、类型检查、Lint 和生产构建。
